# نظام حجز المواعيد للمؤسسات الصغيرة

نظام متكامل لحجز المواعيد في المؤسسات الصغيرة، مبني باستخدام Django + SQLite + Bootstrap.

## المميزات

- ✅ نظام تسجيل دخول للمدير
- ✅ لوحة تحكم متكاملة
- ✅ إدارة المستخدمين
- ✅ إدارة المؤسسات والخدمات
- ✅ إدارة التصنيفات والمدن
- ✅ نظام تقييم متكامل
- ✅ إحصائيات متقدمة
- ✅ تصدير تقارير (CSV, Excel, PDF)
- ✅ إعدادات نظام قابلة للتخصيص
- ✅ دعم كامل للغة العربية
- ✅ تصميم متجاوب

## متطلبات التشغيل

- Python 3.8+
- Django 4.2+
- SQLite3
